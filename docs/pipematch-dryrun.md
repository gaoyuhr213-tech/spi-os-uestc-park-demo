# pipeMatch 规则精度升级 Dry Run 报告

**生成时间**: 2026-08-03
**状态**: Dry Run 完成，未修改当前评分

## 一、问题诊断

现有 `DEFAULT_RULES.pipeMatch` 仅包含11个精确匹配键（软件/AI/芯片/通信/检测/金融/教育/企服/园区/新能源/其他），行业细化后25个行业标签中有17个无法命中规则，涉及37家企业全部回退到默认值25。

**根因**：`calcEntity` 中使用 `rules.pipeMatch[x.ind] ?? 25` 精确字符串匹配，不支持括号、斜杠、多标签、别名。

## 二、解决方案

新增 `server/industryNormalizer.ts`，三级匹配优先级：
1. 精确别名匹配（alias）
2. 上位行业匹配（exact_category）
3. 细分行业匹配（exact_detail）
4. Token 匹配（token）
5. Fallback 默认值25

## 五、说明

- **升分30家**：行业细化后原本应获得的管道匹配分被正确识别（AI/软件/芯片/通信/检测/电子/教育/企服/园区）
- **降分6家**：出版(3家 25→20)和配套(3家 25→15)——这些行业确实与信软管道无关，旧值25是"不知道所以给默认"，新值更准确
- **pipeMatch 不直接影响 Lead Score 评分**：pipeMatch 是独立维度（0-100），不参与 score 计算，仅影响雷达 X 轴排序和匹配率 KPI
- **P0/P1/P2 分布不会因此变化**：tier 由 score 决定，score 由 baseScore + enrichBoost + signalBoost 决定，pipeMatch 不参与
